The flow: Claude Design (brand and plans) → handoff files → GitHub repo → Claude Code builds pages → GitHub → Netlify publishes. Nothing syncs on its own between Claude Design and Claude Code. You move files across by hand, and that's the only manual step.

2. Is GitHub connected to Claude Design?

Not yet. This project has no repository linked, so Claude Design can't see your code. That's fine: it isn't needed to build the site. Connecting it later lets Claude Design read what Claude Code has built and check it against the brand. Step 3.7 shows how.
